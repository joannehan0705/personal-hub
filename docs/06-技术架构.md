## 一、技术选型

### 1.1 总览

| 层级 | 选型 | 理由 |
|------|------|------|
| 框架 | React 18 (CDN) | 组件化开发，生态成熟，CDN 引入无需构建 |
| 状态管理 | React Context + useReducer | 轻量，无额外依赖，适合单用户应用 |
| 数据存储 | IndexedDB (idb 库封装) | 原生支持，容量大，异步不阻塞 UI |
| 路由 | hash-based 自实现 | 无依赖，PWA 友好，刷新不丢失 |
| 样式 | 内联 CSS + CSS 变量 | 无构建，主题切换方便，离线可用 |
| PWA | manifest.json + Service Worker | 离线缓存，添加到主屏幕 |
| 图标 | 内联 SVG | 无外部依赖，可定制 |
| 构建 | **无构建** | 直接运行，维护成本最低 |

### 1.2 为什么不用构建工具？

| 维度 | 无构建 (CDN) | Vite/webpack |
|------|-------------|-------------|
| 部署 | 直接打开 | 需 build |
| 维护 | 零配置 | 依赖更新 |
| 离线 | SW 缓存 CDN | 缓存本地 |
| 换设备 | 复制文件即可 | 需 Node 环境 |
| 开发体验 | 稍弱（无 HMR） | 强 |
| 适合场景 | **个人长期使用** ✅ | 团队协作 |

**结论**：对于个人长期使用的 PWA，无构建方案维护成本最低，换设备零门槛。

### 1.3 依赖清单

```html
<!-- 唯一外部依赖：React 18 -->
<script crossorigin src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"></script>
<script crossorigin src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js"></script>

<!-- IndexedDB 封装（也通过 CDN） -->
<script src="https://unpkg.com/idb@8.0.0/build/umd.js"></script>
```

> 以上 CDN 资源会被 Service Worker 缓存，首次加载后完全离线可用。

## 三、架构分层

```
┌────────────────────────────────────────────────────┐
│                    UI 层 (React)                    │
│  Pages → Components → UI primitives                 │
│  仅负责渲染和用户交互                                │
├────────────────────────────────────────────────────┤
│                  状态层 (Context)                   │
│  AppContext + useReducer                           │
│  全局状态：当前路由、主题、设置、缓存数据             │
├────────────────────────────────────────────────────┤
│                 数据访问层 (DAO)                    │
│  BaseDAO + 各模块 DAO                               │
│  封装所有 IndexedDB 操作                             │
├────────────────────────────────────────────────────┤
│                 存储层 (IndexedDB)                  │
│  原生 IndexedDB + idb 封装                          │
│  本地持久化                                          │
└────────────────────────────────────────────────────┘
```

### 3.1 数据流

```
用户操作 → UI 事件 → 调用 DAO → 读写 IndexedDB
                                    ↓
                              返回结果数据
                                    ↓
                          更新 Context 状态
                                    ↓
                            UI 自动重渲染
```

**单向数据流**，状态变更通过 reducer 集中管理，DAO 只负责持久化。

## 四、路由设计

### 4.1 Hash 路由

使用 `window.location.hash` 实现路由，无需第三方库：

```javascript
// 路由格式: #/path/to/page
// 示例: #/todo, #/finance/add, #/alex/hockey/123

function useHashRoute() {
  const [route, setRoute] = useState(getRouteFromHash());
  
  useEffect(() => {
    const handler = () => setRoute(getRouteFromHash());
    window.addEventListener('hashchange', handler);
    return () => window.removeEventListener('hashchange', handler);
  }, []);
  
  return route;
}

function navigate(path) {
  window.location.hash = path;
}
```

## 七、Service Worker 设计

### 7.1 缓存策略

| 资源类型 | 策略 | 说明 |
|----------|------|------|
| HTML/CSS/JS (本地) | Cache First | 优先缓存，离线可用 |
| React CDN | Cache First | 首次缓存后离线可用 |
| IndexedDB 数据 | 直接访问 | 无需缓存，本地存储 |

### 7.2 Service Worker 代码结构

```javascript
// sw.js
const CACHE_NAME = 'personal-hub-v1';
const ASSETS = [
  './',
  './index.html',
  './assets/styles/theme.css',
  './src/app.js',
  // ... 所有本地资源
  'https://unpkg.com/react@18.3.1/umd/react.production.min.js',
  'https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js',
  'https://unpkg.com/idb@8.0.0/build/umd.js',
];

// 安装：预缓存所有资源
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => cache.addAll(ASSETS))
  );
  self.skipWaiting();
});

// 激活：清理旧缓存
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then(keys => 
      Promise.all(keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k)))
    )
  );
  self.clients.claim();
});

// 拦截请求：Cache First
self.addEventListener('fetch', (event) => {
  // 非 GET 请求直接放行
  if (event.request.method !== 'GET') return;
  
  event.respondWith(
    caches.match(event.request).then(cached => {
      return cached || fetch(event.request).then(response => {
        // 新资源加入缓存
        if (response.ok) {
          const clone = response.clone();
          caches.open(CACHE_NAME).then(cache => cache.put(event.request, clone));
        }
        return response;
      }).catch(() => cached);
    })
  );
});
```

## 十、扩展性设计

### 10.1 新增模块的步骤

1. 在 `db/database.js` 中添加 Object Store
2. 创建 `dao/xxx-dao.js` 继承 BaseDAO
3. 创建 `pages/xxx/` 目录下的页面组件
4. 在路由表中添加路由
5. 在首页添加对应的区块组件
6. 在 FAB 中添加快速新增选项（如需要）

## 十一、安全性考量

| 风险 | 对策 |
|------|------|
| 数据泄露 | 所有数据仅存本地，无网络请求 |
| XSS | React 默认转义，不使用 dangerouslySetInnerHTML |
| CSRF | 无服务器，不存在 |
| 数据丢失 | JSON 备份机制 + 导入前自动备份 |
| 恶意导入 | 导入时校验数据格式 |
