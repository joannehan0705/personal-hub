## 一、产品定位

### 1.1 一句话定义

**Personal Hub 是一个完全本地化、永久免费、离线可用的手机 PWA 应用，作为用户个人生活的统一工作台，管理泡芙品牌、孩子 Alex、宠物、记账、待办、购物、日历等全部生活维度。**

### 1.2 不是什么

| 它不是 | 说明 |
|--------|------|
| 不是静态网页 | 所有数据真实可编辑、可保存 |
| 不是 Dashboard | 不是只读展示，而是完整 CRUD 工具 |
| 不是 Notion 模板 | 独立应用，不依赖第三方平台 |
| 不是 UI 设计稿 | 真正可运行、可长期使用的应用 |
| 不是云端服务 | 零服务器、零登录、零上传 |

### 1.3 核心价值观

```
私密 · 永久 · 离线 · 免费 · 温暖
```

- **私密**：数据永远在用户设备上，不上传、不统计、不追踪
- **永久**：JSON 备份恢复机制，换手机数据不丢
- **离线**：Service Worker 缓存，无网络也能完整使用
- **免费**：100% 无任何付费项，无广告，无第三方服务依赖
- **温暖**：韩系日系极简设计，奶油白基底，让管理生活变成一件舒服的事

## 二、目标用户

**唯一用户：应用所有者本人。**

这是一个 Personal Hub，不为多用户设计，不考虑权限系统，不设登录。所有功能围绕一个人的生活管理展开。

用户画像：
- 经营一个泡芙品牌（anan puff lab）
- 有一个孩子 Alex（涉及 School、IEP、Hockey、Tennis 等多项活动）
- 养一只狗 Cookie 和一只猫 Puff
- 需要日常记账、待办、购物、日历管理
- 重度 iPhone 用户，习惯 Apple 原生应用的设计语言

## 四、各模块功能需求详述

### 4.1 首页（Today Hub）

**目标**：每天打开就能一眼看到今天需要关注的所有信息。

| 区块 | 展示内容 | 交互 |
|------|----------|------|
| 今日概览 | 日期、今日待办数、今日支出、今日订单 | 点击跳转对应模块 |
| 今日待办 | 最多 5 条今日待办 | 点击勾选完成；点击文字进入编辑 |
| 最近提醒 | 未来 3 天的提醒 | 点击查看详情 |
| 购物清单 | 未购买项最多 5 条 | 点击勾选已购 |
| 最近记账 | 今日 3 条最近收支 | 点击进入记账 |
| Alex 今天 | Alex 今日相关活动/任务 | 点击进入 Alex 模块 |
| 宠物提醒 | Cookie/Puff 近期待办（疫苗/洗澡等） | 点击进入宠物模块 |
| 泡芙订单 | 近期待处理订单最多 3 条 | 点击进入订单详情 |

**设计原则**：
- 不放复杂图表，只放列表和数字
- 每个区块都是卡片，留白充足
- 空状态要有温暖提示（如「今天没有待办，享受片刻安静 ☕」）
- 卡片可折叠，记忆折叠状态

### 4.2 To Do（待办）

**目标**：轻量但强大的任务管理，参考 Things 3 的交互体验。

| 功能 | 说明 |
|------|------|
| 新增 | 标题、备注、优先级、日期、分类 |
| 编辑 | 所有字段可编辑 |
| 删除 | 左滑删除，带确认 |
| 完成 | 点击圆圈完成，带动画 |
| 拖动排序 | 长按拖动，支持跨分组 |
| 优先级 | 无/低/中/高，用颜色区分 |
| 分组 | 今天/本周/以后/等待回复/已完成 |

**分组定义**：
- **今天**：日期为今天的任务
- **本周**：日期在本周内但非今天
- **以后**：有日期但在本周之后，或无日期
- **等待回复**：标记为「等待」的任务
- **已完成**：已勾选完成的任务，按完成时间倒序

**交互细节**：
- 左滑显示「完成」「删除」
- 右滑直接完成
- 完成动画：圆圈填充 → 勾选弹入 → 行淡出收拢
- 拖动时有轻微缩放和阴影增强

### 4.3 Shopping List（购物清单）

**目标**：不只是清单，还要帮忙算钱。

| 功能 | 说明 |
|------|------|
| 新增 | 名称、分类、预计价格、购买地点、备注 |
| 删除 | 左滑删除 |
| 勾选已购买 | 点击圆圈，已购项变灰划线 |
| 分类 | 预设分类（食品/日用品/宠物/其他），可自定义 |
| 预计价格 | 数字输入 |
| 购买地点 | 文本输入 |
| 备注 | 文本输入 |
| 自动统计 | 底部固定显示「预计总额」「已购金额」「剩余金额」 |

**预设分类**：
- 🍎 食品
- 🧴 日用品
- 🐾 宠物用品
- 👦 Alex 用品
- 🧁 泡芙原料
- 📦 其他

**交互细节**：
- 已购项自动移到底部
- 分类可折叠
- 长按可拖动排序

### 4.4 Finance（记账）

**目标**：清晰记录每一笔收支，支持分类预算管理。

| 功能 | 说明 |
|------|------|
| 收入记录 | 金额、分类、日期、备注 |
| 支出记录 | 金额、分类、日期、备注 |
| 分类预算 | 每个分类设置月度预算，展示已花/剩余/超支 |
| 按月统计 | 月度收支汇总，收入/支出/结余 |
| 分类统计 | 各分类的支出占比 |
| CSV 导出 | 导出当月或全部记录 |
| 搜索 | 按金额、分类、备注搜索 |
| 编辑 | 所有字段可编辑 |
| 删除 | 左滑删除 |

**支出分类**：
- 🍽️ 餐饮
- 🚗 交通
- 🛒 购物
- 🏠 居家
- 🐾 宠物
- 👦 Alex
- 🧁 泡芙（原料/包装）
- 💊 医疗
- 🎬 娱乐
- 📦 其他

**收入分类**：
- 💰 泡芙收入
- 💵 其他收入

**预算展示**：
- 每个分类一个进度条
- 未超支：鼠尾草绿
- 接近超支（80%+）：蜜蜡黄
- 已超支：珊瑚粉

### 4.5 Alex

**目标**：全方位记录 Alex 的生活与成长。

| 子模块 | 记录内容 |
|--------|----------|
| School | 学校事项、作业、家长会等 |
| IEP | 个别化教育计划相关记录 |
| Hockey | 训练、比赛、装备 |
| Tennis | 课程、训练、比赛 |
| Camp | 夏令营/冬令营信息 |
| Reading | 阅读记录、书单 |
| Medical | 就医、体检、用药 |
| Equipment | 装备采购、维护 |

**每条记录通用字段**：
- 标题
- 日期
| 子模块特有字段 | 说明 |
|----------------|------|
| Hockey/Tennis | 对手/比分/时长 |
| Medical | 诊断/用药/复诊日期 |
| Reading | 书名/作者/完成状态/评分 |
| Equipment | 品牌/价格/状态 |

**交互**：
- 每个子模块独立列表
- 支持新增/编辑/删除
- 顶部 Tab 切换子模块
- 可添加备注和日期

### 4.6 Pets（宠物）

**目标**：Cookie（狗）和 Puff（猫）的独立管理。

**宠物切换**：顶部切换 Cookie / Puff，各自独立数据。

| 记录类型 | 字段 |
|----------|------|
| 医疗 | 日期、诊断、医院、费用、备注 |
| 疫苗 | 疫苗名称、接种日期、下次接种日期、备注 |
| 洗澡 | 日期、地点、费用、下次预约 |
| 用品 | 物品名、价格、购买日期、备注 |
| 饮食 | 食物、品牌、用量、变更记录 |
| 异常观察 | 日期、症状、处理方式、是否就医 |

**提醒机制**：
- 疫苗下次接种日期前 7 天在首页提醒
- 洗澡下次预约日期前 1 天在首页提醒

### 4.7 anan puff lab（泡芙品牌）

**目标**：MVP 版本重点放在订单管理，其余模块基础可用。

| 子模块 | MVP 优先级 | 功能说明 |
|--------|-----------|----------|
| 订单 | P0 | 订单 CRUD、状态流转、日期、顾客、金额 |
| 产品 | P0 | 产品列表、价格、描述 |
| 顾客 | P1 | 顾客信息、历史订单 |
| 配方 | P1 | 配方记录、原料配比 |
| 成本 | P1 | 原料成本、产品成本计算 |
| 库存 | P2 | 简单库存记录（原料/包装） |
| 社交媒体 | P2 | 发布计划、内容记录 |
| 待办 | P1 | 泡芙相关待办 |

**订单状态流转**：
```
新建 → 确认 → 制作中 → 待取货 → 已完成
                              ↘ 已取消
```

**订单字段**：
- 订单号（自动生成）
- 顾客姓名
- 产品（多选）
- 数量
- 金额
- 取货日期
- 状态
- 备注

### 4.8 搜索

**目标**：全局搜索所有模块内容。

| 搜索范围 | 说明 |
|----------|------|
| 待办 | 搜索标题和备注 |
| 购物 | 搜索物品名和备注 |
| 订单 | 搜索顾客和订单号 |
| Alex | 搜索所有子模块标题和备注 |
| 宠物 | 搜索所有记录 |
| 记账 | 搜索分类和备注 |

**交互**：
- 搜索结果按模块分组
- 点击结果直接跳转对应详情
- 搜索历史记录（本地保存）

### 4.9 数据管理

**目标**：数据自主权完全归属用户。

| 功能 | 说明 |
|------|------|
| 导出 JSON | 全量数据导出为一个 JSON 文件 |
| 导入 JSON | 从 JSON 文件恢复数据 |
| CSV 导出 | 记账数据导出为 CSV |
| 清空数据 | 危险操作，需二次确认 |
| 恢复数据 | 导入前的自动备份恢复 |

**安全机制**：
- 清空前自动创建备份
- 导入前可选择「覆盖」或「合并」
- 所有危险操作都有明确的二次确认

## 五、非功能需求

### 5.1 性能

| 指标 | 目标 |
|------|------|
| 首屏加载 | < 1 秒（本地资源） |
| 页面切换 | < 100ms 感知延迟 |
| 数据查询 | < 50ms（IndexedDB） |
| 动画帧率 | 稳定 60fps |

### 5.2 离线能力

- Service Worker 缓存所有静态资源
- 首次加载后完全离线可用
- 无任何在线依赖

### 5.3 数据安全

- 所有数据仅存于 IndexedDB
- LocalStorage 仅存设置项（主题、折叠状态等）
- 无任何网络请求发送用户数据
- 无第三方追踪脚本

### 5.4 兼容性

- 优先适配 iPhone（Safari/Chrome on iOS）
- 兼容 Android Chrome
- 最低支持 iOS 15+
- 支持深色模式

## 六、MVP 范围

### 6.1 MVP 必做（v1.0）

| 模块 | 功能范围 |
|------|----------|
| 首页 | 全部 8 个区块 |
| To Do | 新增/编辑/删除/完成/拖动排序/优先级/分组 |
| Shopping | 新增/删除/勾选/分类/价格/统计 |
| Finance | 收入/支出/分类预算/月度统计/CSV 导出/搜索 |

| Pets | Cookie/Puff 各 6 类记录的 CRUD + 提醒 |
| 泡芙订单 | 订单 CRUD + 状态流转 + 产品管理 |
| 搜索 | 全局搜索 6 大模块 |
| 本地保存 | IndexedDB + LocalStorage |

- AI 聊天
- 云端同步
- 多用户/登录
- 复杂图表
- 推送通知（后续版本考虑）
- 日历视图（先做提醒列表，日历网格后续）

## 七、成功标准

1. **可用性**：所有 MVP 功能在 iPhone Safari 上流畅运行，添加到主屏幕后体验等同原生 App
2. **完整性**：每个模块的 CRUD 全部可用，数据真实保存，无 placeholder
3. **离线性**：断网后所有功能正常使用
4. **数据安全**：JSON 备份恢复经过测试，数据不丢
5. **体验**：操作流畅，动画自然，单手可完成所有操作

## 八、风险与对策

| 风险 | 对策 |
|------|------|
| IndexedDB 兼容性问题 | 使用成熟封装库，做好 try-catch 降级 |
| PWA 在 iOS Safari 限制 | 不依赖 Push Notification，用日期轮询提醒 |
| 数据量增长后性能 | 轻量使用场景（几百条），加索引可保障 |
| CDN 依赖 | 核心框架缓存到 Service Worker，离线可用 |
