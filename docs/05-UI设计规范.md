# Personal Hub — UI 设计规范

> 版本：v1.0 MVP
> 更新日期：2026-07-28
> 设计哲学：**温暖的克制** — 奶油白为底、暖墨色为文、低饱和粉彩为语义，用大面积留白营造呼吸感

---

## 一、设计原则

### 1.1 五大设计原则

| 原则 | 说明 | 参考 |
|------|------|------|
| **色彩克制** | 界面 95% 为中性色，颜色仅承载语义信息 | Things 3 的 95/5 原则 |
| **大面积留白** | 充足的间距和呼吸感，而非信息密度 | Craft 的 "a breath of air" |
| **柔和温度** | 奶油白底色、暖墨色文字，不冰冷 | 韩系暖白 + 日系暖灰 |
| **统一圆角** | 所有交互元素统一圆角，传达柔和 | Things 3 的 18px 大圆角 |
| **单手优先** | 所有主要交互在屏幕底部 1/3 区域 | iOS 26 HIG |

### 1.2 设计不做的事

- ❌ 不用纯白 `#FFFFFF` 作为背景（用奶油白）
- ❌ 不用纯黑 `#000000` 作为文字（用暖墨色）
- ❌ 不用硬阴影
- ❌ 不用大写字母装饰
- ❌ 不用过于饱和的颜色
- ❌ 不在顶部放置主要操作按钮

## 三、字体系统

### 3.1 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Text',
             'PingFang SC', 'Hiragino Sans GB', system-ui, sans-serif;
```

> iOS 渲染为 San Francisco + 苹方，Android/Web 回退到系统无衬线字体。

### 3.2 字体层级

| 层级 | 字号 | 字重 | 行高 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| 大标题 | 34px | 700 | 41px | -0.01em | 首页顶部大日期 |
| 页面标题 | 22px | 600 | 28px | 0 | 各页面顶部标题 |
| 区块标题 | 17px | 600 | 22px | -0.005em | Section header |
| 正文 | 17px | 400 | 22px | -0.005em | 任务标题、列表项 |
| 次要文本 | 15px | 400 | 20px | -0.005em | 副信息、备注 |
| 辅助文本 | 13px | 400 | 18px | 0 | 日期、标签 |
| 三级文本 | 12px | 400 | 16px | 0 | 时间戳、计数 |
| Tab 标签 | 11px | 400 | 14px | 0.02em | 底部导航文字 |

### 3.3 字体使用原则

1. **以字重和颜色区分层级，而非字号** — 通过 Regular → Semibold → Bold 建立层级
2. **标题用 Semibold 不用 Bold** — Bold 仅保留给大标题
3. **不用大写字母装饰** — 保持中英文自然排版
4. **数字用 SF Pro Rounded** — 统计数字使用 `font-variant-numeric: tabular-nums` 等宽对齐

## 六、阴影系统

```css
/* 层级 1：微浮起 — 列表项选中态 */
--shadow-1: 0 1px 3px rgba(45, 42, 38, 0.04);

/* 层级 2：卡片默认 */
--shadow-2: 0 2px 8px rgba(45, 42, 38, 0.05);

/* 层级 3：卡片悬停/拖拽 */
--shadow-3: 0 4px 16px rgba(45, 42, 38, 0.08);

/* 层级 4：浮层 — 底部 Sheet */
--shadow-4: 0 8px 32px rgba(45, 42, 38, 0.10);

/* 层级 5：模态 */
--shadow-5: 0 16px 48px rgba(45, 42, 38, 0.15);

/* 聚焦环 */
--shadow-focus: 0 0 0 3px rgba(91, 138, 142, 0.15);

/* 拖拽态 */
--shadow-drag: 0 4px 12px rgba(45, 42, 38, 0.12),
               0 0 0 2px rgba(91, 138, 142, 0.3);
```

**阴影原则**：
1. 颜色用暖色调 `rgba(45,42,38,X)` 而非纯黑
2. 模糊半径 > 偏移量，营造柔和扩散感
3. 静态状态极淡（opacity 0.04-0.05）

## 七、组件规范

### 7.1 底部 Tab Bar

```
┌──────────────────────────────────────────┐
│                                          │
│   🏠      🧁      👦      💰      👤   │
│  首页    泡芙    Alex    记账    我的    │

- 位置：固定底部，悬浮于内容之上
- 背景：奶油白 `#FAF8F5`，带顶部 1px 边框 `rgba(0,0,0,0.06)`
- 高度：49px + 底部安全区域 34px = 83px
- 图标：28px，线条风格
- 文字：11px Regular
- 选中态：图标+文字变为主强调色 `#5B8A8E`
- 未选中：图标+文字为 `#9C968B`
- 切换动画：图标缩放 0.96→1，颜色渐变

```

                    │  +   │
                    └──────┘

## 八、交互动效规范

### 8.1 动效时长

| 类型 | 时长 | 缓动 |
|------|------|------|
| 按钮按下 | 100ms | ease-out |
| 卡片悬停 | 200ms | ease-in-out |
| 列表展开 | 300ms | spring(0.3, 0.8) |
| 页面转场 | 350ms | ease-in-out |
| 底部 Sheet | 250ms | spring(0.4, 0.8) |
| 任务完成 | 500ms | 三阶段 |

### 8.2 交互反馈

| 交互 | 效果 |
|------|------|
| 按钮点击 | scale(0.96-0.97) |
| 卡片点击 | translateY(-1px) + 阴影增强 |
| 列表项左滑 | 显示操作按钮，阻尼回弹 |
| 拖拽排序 | 轻微缩放(1.02) + 阴影增强 |
| 下拉刷新 | 旋转加载指示器 |
| Tab 切换 | 图标缩放 + 颜色渐变 |

### 8.3 触觉反馈（iOS）

| 场景 | 反馈类型 |
|------|----------|
| 完成任务 | notification(success) |
| 按钮点击 | light |
| 长按拖拽 | medium |
| 删除操作 | warning |
| 错误提示 | error |

> 通过 `navigator.vibrate()` 在 Android 上提供振动反馈；iOS Safari 上使用 Web Audio API 模拟。

### 8.4 无障碍

- 所有可点击元素提供 44px × 44px 最小触控区域
- 支持 `prefers-reduced-motion`：减少动画时使用淡入淡出替代位移
- 颜色对比度：主文字 ≥ 7:1 (AAA)，次要文字 ≥ 4.5:1 (AA)
- 提供 ARIA 标签

## 十、深色模式适配

### 10.1 切换策略

- 支持 `prefers-color-scheme: auto` 自动跟随系统
- 支持手动切换（亮/暗/自动）
- 通过 CSS 变量实现，切换时无闪烁

### 10.2 实现方式

```css
:root {
  --color-bg-base: #FAF8F5;
  --color-text-primary: #2D2A26;
  /* ... 浅色模式变量 */
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-base: #1C1A17;
    --color-text-primary: #F0EDE8;
    /* ... 深色模式变量 */
  }
}

/* 手动切换时通过 data-theme 属性覆盖 */
[data-theme="dark"] {
  --color-bg-base: #1C1A17;
  --color-text-primary: #F0EDE8;
}
```
