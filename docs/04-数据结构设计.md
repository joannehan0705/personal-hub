## 一、IndexedDB 总体设计

### 1.1 数据库名称

```
personal-hub-db
```

### 1.2 版本

```
version: 1
```

### 1.3 Object Stores（表）一览

| Store 名称 | 用途 | 主键 | 索引 |
|-----------|------|------|------|
| `todos` | 待办事项 | id | status, priority, date, category, completedAt |
| `shopping` | 购物清单 | id | category, purchased, name |
| `transactions` | 收支记录 | id | type, category, date, amount |
| `budgets` | 预算设置 | id | category, month |
| `alex` | Alex 记录 | id | category, date |
| `pets` | 宠物记录 | id | petName, type, date, nextDate |
| `orders` | 泡芙订单 | id | status, customer, pickupDate, orderNumber |
| `products` | 泡芙产品 | id | name, active |
| `customers` | 顾客 | id | name |
| `recipes` | 配方 | id | name |
| `inventory` | 库存 | id | name, category |
| `puffTodos` | 泡芙待办 | id | status, date |
| `socialPosts` | 社交媒体 | id | platform, scheduledDate, status |
| `meta` | 元数据（自增ID、版本等） | key | — |

### 1.4 ID 生成策略

使用 `Date.now()` + 随机后缀生成唯一 ID：

```javascript
function generateId() {
  return `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
}
// 示例: "1722164820512-a3b8x9k2m"
```

各 Store 也维护一个自增序号（存在 `meta` 表），用于生成订单号等需要人类可读的编号。

## 二、各 Store 详细 Schema

### 2.1 todos（待办）

```javascript
{
  id: "1722164820512-a3b8x9k2m",     // 主键，自动生成
  title: "买泡芙原料",                 // 标题，必填
  notes: "需要面粉、黄油、鸡蛋",       // 备注，选填
  priority: "high",                   // 优先级: "none" | "low" | "medium" | "high"
  date: "2026-07-28",                // 计划日期，ISO 日期字符串，选填
  category: "default",               // 分类标签，选填
  status: "today",                   // 状态分组: "today" | "week" | "later" | "waiting" | "completed"
  completed: false,                  // 是否完成
  completedAt: null,                 // 完成时间，ISO 时间戳，未完成为 null
  sortOrder: 0,                      // 同组内排序顺序，拖拽时更新
  createdAt: "2026-07-28T10:00:00Z", // 创建时间
  updatedAt: "2026-07-28T10:00:00Z"  // 更新时间
}
```

**索引说明**：
- `status`：用于按分组查询（今天/本周/以后/等待/已完成）
- `priority`：用于优先级排序
- `date`：用于按日期查询
- `completedAt`：用于已完成列表按时间排序
- 复合查询：`status = "today" AND completed = false`

## 五、数据访问层（DAO）设计

### 5.1 统一 DB 操作接口

```javascript
// 所有 Store 共享的基础 CRUD 方法

class BaseDAO {
  constructor(storeName) {
    this.storeName = storeName;
  }

  // 新增
  async create(data) {
    const id = generateId();
    const now = new Date().toISOString();
    const record = {
      ...data,
      id,
      createdAt: now,
      updatedAt: now
    };
    await db.put(this.storeName, record);
    return record;
  }

  // 按 ID 查询
  async getById(id) {
    return await db.get(this.storeName, id);
  }

  // 查询全部
  async getAll() {
    return await db.getAll(this.storeName);
  }

  // 按索引查询
  async getByIndex(indexName, value) {
    return await db.getAllFromIndex(this.storeName, indexName, value);
  }

  // 更新
  async update(id, updates) {
    const existing = await this.getById(id);
    if (!existing) throw new Error('Record not found');
    const updated = {
      ...existing,
      ...updates,
      id,  // 确保 ID 不被覆盖
      updatedAt: new Date().toISOString()
    };
    await db.put(this.storeName, updated);
    return updated;
  }

  // 删除
  async delete(id) {
    await db.delete(this.storeName, id);
  }

  // 清空
  async clear() {
    await db.clear(this.storeName);
  }

  // 批量写入（用于导入）
  async bulkPut(records) {
    const tx = db.transaction(this.storeName, 'readwrite');
    await Promise.all(records.map(r => tx.store.put(r)));
    await tx.done;
  }
}
```

### 6.3 导入策略

| 模式 | 行为 |
|------|------|
| **覆盖** | 清空目标 Store，写入导入数据 |
| **合并** | 按 ID 判断：ID 已存在则跳过（保留本地），不存在则新增 |

导入前自动创建一份当前数据的备份（存储在 `meta` 表的 `lastBackupBeforeImport` 字段），用于「恢复数据」功能。

## 八、数据安全与完整性

### 8.1 数据校验

```javascript
// 导入时校验数据格式
function validateImportData(data) {
  const requiredStores = [
    'todos', 'shopping', 'transactions', 'budgets',
    'alex', 'pets', 'orders', 'products'
  ];
  
  // 检查版本
  if (!data.version) throw new Error('无效的备份文件：缺少版本信息');
  
  // 检查数据结构
  if (!data.data) throw new Error('无效的备份文件：缺少数据');
  
  // 检查必需的 Store
  for (const store of requiredStores) {
    if (!Array.isArray(data.data[store])) {
      throw new Error(`无效的备份文件：${store} 数据格式错误`);
    }
  }
  
  return true;
}
```
