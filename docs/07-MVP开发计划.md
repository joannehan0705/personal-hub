## 一、开发阶段总览

```
Phase 0: 基础设施搭建          ──→  Phase 1: 核心模块开发  ──→  Phase 2: 集成与打磨  ──→  Phase 3: PWA 与交付
```

| 阶段 | 内容 | 预计工作量 |
|------|------|-----------|
| Phase 0 | 项目骨架、DB、UI 组件库、路由 | 高 |

## 七、技术风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| CDN 不可用导致首次加载失败 | 低 | 高 | 提供本地 fallback 版本注释 |
| IndexedDB 在 iOS Safari Private Mode 下被禁用 | 低 | 高 | 检测可用性，提示用户使用普通模式 |
| 拖拽排序在移动端体验不佳 | 中 | 中 | 使用成熟的手势处理逻辑，充分测试 |
| Service Worker 更新缓存不及时 | 中 | 低 | 版本号管理 + skipWaiting |
| 数据导入大文件性能问题 | 低 | 低 | 轻量使用场景，几百条数据无压力 |
