## 二、路由结构

```
/                        → 首页（Today Hub）
/todo                    → 待办完整列表
/todo/:id                → 待办详情/编辑
/shopping                → 购物清单完整列表
/finance                 → 记账主页
/finance/add             → 新增收支
/finance/:id             → 编辑收支
/finance/stats           → 统计
/finance/budget          → 预算管理
/alex                    → Alex 主页（子模块切换）
/alex/:category          → Alex 子模块列表
/alex/:category/:id      → Alex 记录详情
/pets                    → 宠物主页（Cookie/Puff 切换）
/pets/:pet/:type         → 宠物记录列表
/pets/:pet/:type/:id     → 宠物记录详情
/puff                    → 泡芙品牌主页
/puff/orders             → 订单列表
/puff/orders/:id         → 订单详情/编辑
/puff/products           → 产品列表
/puff/products/:id       → 产品详情/编辑
/puff/customers          → 顾客列表
/puff/customers/:id      → 顾客详情
/puff/recipes            → 配方列表
/puff/inventory          → 库存
/puff/social             → 社交媒体
/settings                → 我的/设置
/settings/search         → 全局搜索
/settings/data           → 数据管理
/settings/preferences    → 偏好设置
/settings/about          → 关于
```

## 五、Sheet 与模态层

所有新增和编辑操作使用**底部 Sheet** 而非全屏页面跳转，符合单手操作原则：

```
┌─────────────────────────────────┐
│                                 │
│  (页面内容变暗，不可点击)        │
│                                 │
│                                 │
├─────────────────────────────────┤  ← Sheet 顶部圆角
│           ━━━                   │  ← 拖拽指示器
│                                 │
│  新增待办                        │  ← Sheet 标题
│                                 │
│  ┌───────────────────────────┐ │
│  │ 输入标题...               │ │  ← 表单内容
│  └───────────────────────────┘ │
│                                 │
│  优先级：[无] [低] [中] [高]    │
│  日期：   今天 ▾               │
│  分类：   默认 ▾               │
│                                 │
│  ┌───────────────────────────┐ │
│  │       保存                 │ │  ← 主操作按钮
│  └───────────────────────────┘ │
│                                 │
└─────────────────────────────────┘
```
