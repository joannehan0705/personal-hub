# Personal Hub

> 个人生活管理工作台 — 100% 本地 · 永久免费 · 离线可用

## 快速开始

### 在 iPhone 上使用（推荐）

1. 将 `personal-hub` 整个文件夹放到任何可托管静态文件的地方
2. 在 iPhone Safari 中打开 `index.html`
3. 点击 Safari 底部的分享按钮 →「添加到主屏幕」
4. 从主屏幕打开，全屏使用，体验等同原生 App

### 本地运行

```bash
# 在项目目录下启动一个简单的 HTTP 服务器
python3 -m http.server 8000

# 然后在浏览器中打开
# http://localhost:8000
```

### 离线使用

首次加载后，Service Worker 会缓存所有资源，之后完全离线可用。

## 功能模块

| 模块 | 功能 |
|------|------|
| 🏠 首页 | 今日概览、待办、提醒、购物、记账、Alex、宠物、订单聚合 |
| 📋 待办 | 新增/编辑/删除/完成、优先级、分组（今天/本周/以后/等待/已完成） |
| 🛒 购物 | 分类管理、预计价格、购买地点、自动统计金额 |
| 💰 记账 | 收入/支出、分类预算、月度统计、CSV 导出、搜索 |
| 👦 Alex | School/IEP/Hockey/Tennis/Camp/Reading/Medical/Equipment |
| 🐾 宠物 | Cookie(狗) & Puff(猫)，医疗/疫苗/洗澡/用品/饮食/异常观察 |
| 🧁 泡芙 | 订单管理（状态流转）、产品、顾客、配方、库存、社交媒体 |
| 🔍 搜索 | 全局搜索所有模块内容 |
| 💾 数据 | JSON 导出/导入、CSV 导出、清空/恢复 |

## 技术栈

- **React 18** (CDN，无构建工具)
- **IndexedDB** (idb 库封装，本地数据存储)
- **Service Worker** (离线缓存)
- **CSS 变量** (主题切换，浅色/深色模式)
- **PWA** (可添加到主屏幕，全屏运行)

## 数据安全

- 所有数据仅存储在设备本地的 IndexedDB 中
- 无服务器、无登录、无云端、无追踪
- JSON 备份/恢复：换手机时数据不丢
- 清空前自动备份，可随时恢复

## 项目结构

```
personal-hub/
├── index.html              # 入口
├── manifest.json           # PWA 配置
├── sw.js                   # Service Worker
├── assets/
│   ├── icons/              # PWA 图标
│   └── styles/theme.css    # 全局样式（CSS 变量）
├── src/
│   ├── app.js              # 根组件 + 路由
│   ├── constants/          # 配置常量
│   ├── utils/              # 工具函数（日期、格式化、备份等）
│   ├── db/                 # IndexedDB 数据层
│   ├── store/              # 全局状态管理
│   ├── components/         # UI 组件库 + 布局组件
│   └── pages/              # 各功能页面
└── docs/                   # 项目文档（PRD、设计规范等）
```

## 设计风格

- **奶油白** 基底 (#FAF8F5)，暖墨色文字 (#2D2A26)
- **低饱和粉彩** 语义色，颜色出现即意味着信息
- **大面积留白**，圆角卡片，柔和阴影
- **单手操作**，所有主要交互在屏幕底部 1/3
- 支持 **浅色/深色/跟随系统** 三种模式
